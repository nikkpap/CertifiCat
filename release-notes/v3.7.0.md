## CertifiCat 3.7.0 🐱

### Νέο: ⑤ Δωρεάν υπογραφή για Open Source
Εκτός από τα self-signed πιστοποιητικά, το CertifiCat σας οδηγεί πλέον στη **δωρεάν, δημόσια αναγνωρισμένη** υπογραφή του
**SignPath Foundation** για έργα ανοιχτού κώδικα. Τα Windows την αναγνωρίζουν σε **κάθε** υπολογιστή, χωρίς εγκατάσταση .cer.

- **Σύγκριση επιλογών:** self-signed, SignPath Foundation, Microsoft Store (MSIX), αγορά πιστοποιητικού, Azure Artifact Signing.
- **Έλεγχος repo:** γράφετε το GitHub repo σας και βλέπετε αμέσως αν είναι δημόσιο, αν έχει άδεια OSI, release, ενεργή συντήρηση
  και ενότητα «Code signing policy». Ο έλεγχος γίνεται ανώνυμα, χωρίς κανένα κλειδί.
- **Αυτόματα αρχεία:** με ένα κλικ φτιάχνονται το GitHub Actions workflow (build → SignPath → υπογεγραμμένο exe στο release),
  το `CODE_SIGNING_POLICY.md`, η ενότητα του README και το `artifact-configuration.xml`.
- Κουμπιά για την αίτηση, τις προϋποθέσεις και τις οδηγίες.

> Με το SignPath Foundation ο εκδότης που εμφανίζεται είναι το «SignPath Foundation». Χρειάζεται άδεια OSI, δημόσιο repo,
> build στο GitHub Actions και έγκριση κάθε release.
