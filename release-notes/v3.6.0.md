## CertifiCat 3.6.0 🐱

Η πρώτη δημόσια έκδοση της νέας γενιάς CertifiCat (PyQt6). Από εδώ και πέρα η εφαρμογή **ενημερώνεται μόνη της**.

### Νέο στην 3.6
- **🐙 GitHub Actions:** το κουμπί «GitHub» (βήμα ① ή Κλειδοθήκη ④) δίνει το `.pfx` σε **Base64** και τον κωδικό για τα
  *Secrets* του repo (`CERT_PFX_BASE64`, `CERT_PASSWORD`), μαζί με έτοιμο workflow για αυτόματη υπογραφή σε κάθε build.
  Το πρόχειρο καθαρίζει αυτόματα.
- **Dark mode των Windows:** διορθώθηκαν τα «αόρατα» κείμενα· το παράθυρο χωράει πάντα στην οθόνη (κλίμακα 125–150%).

### Όλα όσα έφερε η νέα έκδοση (3.5)
- 4 βήματα: ① Πιστοποιητικό → ② Υπογραφή → ③ Εγκατάσταση & διανομή → ④ Κλειδοθήκη
- **Κλειδοθήκη:** όλα τα πιστοποιητικά σας· ο κωδικός μόνο αν το επιλέξετε, κρυπτογραφημένος (DPAPI), τοπικά
- **Αυτόματες ενημερώσεις (OTA)** από τα GitHub Releases, με έλεγχο SHA-256 — χωρίς κανένα token/μυστικό
- Πιστοποιητικά **μόνο για υπογραφή κώδικα** (CA:FALSE)
- Υπογραφή exe/dll/msi/ps1/msix… σε δέσμες, **αυτόματη εναλλαγή διακομιστή χρονοσήμανσης**, έλεγχος μετά την υπογραφή
- **Δεξί κλικ → Αποστολή προς → CertifiCat** και `--sign` για build scripts
- Πακέτο εγκατάστασης (.zip + .bat) για άλλους υπολογιστές, «για εμένα» ή «για όλους»

### Εγκατάσταση
Windows 10/11 · Python 3.9+ → κατεβάστε το `CertifiCat_v3.6.pyw` και κάντε διπλό κλικ. Οι βιβλιοθήκες εγκαθίστανται μόνες τους.

> Από το παλιό v2.5: κατεβάστε χειροκίνητα μία φορά — μετά οι ενημερώσεις έρχονται αυτόματα.
